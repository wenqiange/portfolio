# Textures Directory

Carpeta opcional para texturas adicionales de Minecraft.

## Nota:
Las texturas principales están creadas con CSS puro (patrones, gradientes).
Si deseas agregar texturas reales de Minecraft, colócalas aquí.

## Recursos gratuitos:
- [Minecraft Texture Pack](https://minecraft.fandom.com/wiki/Resource_pack)
- [Pixel Art Makers](https://www.piskelapp.com/)
