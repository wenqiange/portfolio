# Images Directory

Coloca aquí las imágenes/thumbnails de tus proyectos.

## Recomendaciones:
- **Formato**: JPG o PNG (WebP para mejor rendimiento)
- **Tamaño**: 800x450px (ratio 16:9) o 400x400px (cuadrado)
- **Compresión**: Optimiza las imágenes antes de subirlas
- **Naming**: Usa nombres descriptivos (ej: `proyecto-web-app.jpg`)

## Herramientas de optimización:
- [TinyPNG](https://tinypng.com/) - Compresión online
- [Squoosh](https://squoosh.app/) - Herramienta de Google
